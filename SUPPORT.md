# Support

For plugin bugs, open an issue in this repository or email hello@rankbeam.dev. Include the plugin version, operating system, PHP version and a small redacted example of the failing command or workflow. Please do not include `.env`, Composer credentials, customer records or production HTML containing private data.

For Rankbeam package usage, see [the documentation](https://docs.rankbeam.dev). A plugin bug and an application/package issue may have different fixes; include the installed Core version when relevant.

This plugin works with a local project and the host's file/shell tools. A directory listing alone does not provide access to a local Laravel application from every ChatGPT surface.
